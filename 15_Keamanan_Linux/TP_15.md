# 📝 Dasar Teori

## 1. Integritas Data dan Fungsi Hash

Integritas merupakan aspek keamanan yang bertujuan memastikan bahwa data tidak mengalami perubahan tanpa izin selama proses penyimpanan maupun transmisi. Salah satu metode yang digunakan untuk memverifikasi integritas data adalah fungsi hash kriptografi seperti MD5, SHA256, dan SHA512.

Fungsi hash bekerja dengan menghasilkan nilai unik berdasarkan isi suatu file. Apabila isi file berubah meskipun hanya satu karakter, maka nilai hash yang dihasilkan akan berubah secara signifikan. Oleh karena itu, hash sering digunakan untuk memverifikasi keaslian dan konsistensi data.

---

## 2. Avalanche Effect

Avalanche Effect merupakan sifat penting dalam algoritma hash kriptografi. Efek ini menyatakan bahwa perubahan yang sangat kecil pada data masukan akan menghasilkan perubahan yang sangat besar pada nilai hash keluaran.

Karakteristik ini membuat fungsi hash efektif digunakan untuk mendeteksi modifikasi data karena perubahan sekecil apa pun akan menghasilkan hash yang berbeda secara drastis.

---

## 3. Metadata File

Selain isi utama file, sebuah dokumen juga menyimpan metadata seperti waktu pembuatan, waktu modifikasi, nama aplikasi, dan informasi lainnya. Perubahan metadata dapat menyebabkan nilai hash berubah meskipun isi dokumen terlihat sama.

Hal ini menunjukkan bahwa fungsi hash tidak hanya dipengaruhi oleh isi yang terlihat oleh pengguna, tetapi juga oleh struktur internal file secara keseluruhan.

---

## 4. EncFS dan Enkripsi Sistem Berkas

EncFS merupakan aplikasi yang digunakan untuk membuat sistem berkas terenkripsi pada Linux. EncFS bekerja dengan menghubungkan dua direktori, yaitu direktori normal dan direktori terenkripsi.

File yang disimpan pada direktori normal akan otomatis disimpan dalam bentuk terenkripsi pada direktori terenkripsi. Dengan mekanisme ini, data tetap aman walaupun file fisik berhasil diakses oleh pihak lain.

---

## 5. GNU Privacy Guard (GPG)

GNU Privacy Guard (GPG) merupakan implementasi kriptografi asimetris yang menggunakan pasangan kunci publik dan kunci privat.

Kunci publik digunakan untuk mengenkripsi pesan atau file yang akan dikirim kepada seseorang, sedangkan kunci privat digunakan untuk membuka kembali data yang telah dienkripsi tersebut. Dengan mekanisme ini, hanya pemilik kunci privat yang dapat membaca isi pesan yang dikirimkan.
